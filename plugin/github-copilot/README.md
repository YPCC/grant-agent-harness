# GitHub Copilot plugin

1. `pip install -e .` so `grant-harness` is on PATH.
2. Open this repo (or add `.vscode/mcp.json` to the grant-agent-lab workspace).
3. In Copilot Chat / Agent mode, enable MCP server **grant-agent-harness**.
4. Ask: "Run the weak_aims_vague harness case" or "Review this Specific Aims page."

Copilot should call MCP tools rather than inventing checklist scores.

This is an MCP plugin, not a GitHub App Copilot Extension. No marketplace listing is required for workspace use.
